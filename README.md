# 🕹️ 퍼스트플러그인

마인크래프트 서버에서 즐기는 **⚔️ 능력 대전** 플러그인입니다.
모두가 서로 다른 능력을 골라 시작하고, 마지막까지 살아남는 사람(또는 팀)이 승리합니다.

|---|---|
| 🎮 [게임 진행 방법](guide/how-to-play.md) | 게임이 시작되고 끝나기까지의 흐름 |
| 💬 [명령어 가이드](guide/commands.md) | 모든 명령어와 사용법 |
| ⚙️ [게임 설정 가이드](guide/settings.md) | `/game 설정`의 각 항목이 하는 일 |
| 🧬 [특성 안내](guide/traits.md) | 특성 시스템과 특성별 효과 |
| 📖 [능력 도감](abilities/README.md) | 모든 능력의 스킬·쿨타임·효과 |
| 📰 [패치노트](patchnotes/README.md) | 버전별 변경 사항 |

## 🚀 처음 시작하는 분께

1. 🎯 `/능력` 으로 능력을 고릅니다.
2. ✅ 모두가 고르면 `/game start` 로 게임을 시작합니다.
3. ⌨️ 능력 아이템을 손에 들고 **F키**를 눌러 스킬을 사용합니다.
4. 🏆 마지막까지 살아남으세요!
