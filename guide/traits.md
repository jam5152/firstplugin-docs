# 🧬 특성 안내

[게임 설정](settings.md)에서 **특성 시스템 활성화**를 켜면, 능력과 별개로 **특성**을 하나 더 고르게 됩니다. `/특성` 으로 특성 선택 창을 열 수 있습니다.

- 특성 시스템이 켜져 있으면 **모든 인원이 능력과 특성을 모두 골라야** 게임을 시작할 수 있습니다.
- 특성은 능력 위에 더해지는 기본 스탯 보너스이며, 하나만 고를 수 있습니다.

## 🏷️ 특성별 효과

| 특성 | 효과 |
|:-:|---|
| **B** | 최대 체력 +하트 4칸 (기본 체력 + 8) |
| **C** | 공격력 증가 (기본의 150%) |
| **E** | 이동속도 증가 (기본의 120%) |
| **F** | 공격 사거리 증가 (대상 3.5블록 / 블록 5.0블록) |
| **G** | 자연 회복 주기 단축 (4초 → 2초마다 회복) |
| **H** | 자연 회복량 증가 (한 번에 1 → 2 회복) |
| A, D | 정보 준비 중 |

## 💚 자연 회복

특성 시스템을 켜면 게임 중 **4초마다 체력 1(하트 반 칸)** 이 자연 회복됩니다. 특성 G는 회복 주기가 짧아지고, 특성 H는 한 번에 회복하는 양이 늘어납니다. 특성은 하나만 고를 수 있으니 자신의 능력과 어울리는 쪽을 고르세요.

> 🕷️ **거미여왕**은 능력 자체가 공격 사거리를 20% 늘려 주기 때문에, 특성 F를 골라도 사거리 효과가 중복으로 더해지지 않습니다.
