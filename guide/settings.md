# ⚙️ 게임 설정 가이드

`/game 설정` (관리자 전용)으로 설정 창을 엽니다. 항목을 클릭하면 켜짐/꺼짐이 바뀌며, **바꾼 즉시 자동 저장**되어 서버를 다시 켜도 유지됩니다.

## 🧰 설정 항목

| 항목 | 기본값 | 설명 |
|---|:-:|---|
| 🙈 능력 선택 숨기기 | 꺼짐 | 켜면 누가 어떤 능력을 골랐는지 공개되지 않습니다. 본인에게만 자기 능력이 표시되고, 다른 사람에게는 "누가 능력을 선택했다"는 사실만 알려집니다. |
| 👯 중복 능력 허용 | 꺼짐 | 켜면 같은 능력을 여러 명이 고를 수 있습니다. 끄면 이미 다른 사람이 고른 능력은 고를 수 없습니다. |
| ☠️ 데스매치 모드 | 꺼짐 | 켜면 게임 시작 **120초 후부터 5초마다** 모든 생존자가 하트 반 칸(피해 1)을 입습니다. 오래 버티는 전략을 막아 줍니다. |
| 🎲 게임 모드 | 개인전 | **개인전**: 마지막 한 명이 승리. **팀전**: 시작 시 인원을 무작위로 절반씩 나눠 마지막 팀이 승리. |
| ⏳ 시작 30초 능력제한 | 꺼짐 | 게임 시작 직후 30초 동안 능력 사용을 제한하는 옵션입니다. |
| 🧬 특성 시스템 활성화 | 꺼짐 | 켜면 모두가 `/특성` 으로 특성을 골라야 하고, 특성 효과가 적용됩니다. [특성 안내](traits.md) 참고. |
| 🧭 시작 시 랜덤 위치 이동 | 꺼짐 | 켜면 게임이 시작될 때 모든 플레이어가 월드보더 안의 **무작위 안전한 위치**로 이동합니다. 안전한 위치는 "발밑이 단단한 땅이고, 몸이 블록에 끼지 않으며, 물·용암·불·선인장 등이 없는 곳"입니다. 안전하지 않은 곳이 걸리면 안전한 곳이 나올 때까지 다른 위치를 다시 고릅니다. |
| ❤️ 기본 체력 | 20 | 게임 시작 시 모든 플레이어의 최대 체력입니다. |

## ❤️ 기본 체력 바꾸는 법

1. `/game 설정` 에서 **기본 체력** 항목을 클릭합니다.
2. 설정 창이 닫히고 채팅 입력 상태가 됩니다.
3. 채팅에 **숫자**를 입력합니다. (1 ~ 1024)
4. 입력한 값이 바로 적용됩니다.

- 숫자는 체력 수치이며 **하트 1칸 = 2** 입니다. 기본값 20은 하트 10칸입니다.
- 예: `40` 을 입력하면 하트 20칸으로 시작합니다.

## 💡 알아두면 좋은 점

- 설정은 `settings.yml` 파일에 저장됩니다.
- 설정은 **게임을 시작하기 전에** 바꾸세요. 진행 중인 게임에는 기본 체력 같은 값이 다시 적용되지 않습니다.
- 금지할 능력을 정하는 것은 설정 창이 아니라 `/game 금지` 또는 `/능력금지` 입니다. ([명령어 가이드](commands.md))
